#

### О программе

Управлять файлом hosts можно и с помощью обычного блокнота. Однако делать это с помощью шустрой утилиты с современным интерфейсом гораздо приятнее.

Программа разработана для улучшения пользовательского опыта при настройке системы. Каждая запись представлена в виде отдельной карточки с интуитивно понятным дизайном: в ней отображаются IP-адрес, доменное имя и комментарий. Элементы управления расположены справа и сразу дают понять, активна ли запись.

> [!Tip]
> Чтобы скопировать IP-адрес, достаточно нажать на него.
> Чтобы отредактировать существующую запись, нажмите на её доменное имя или комментарий.

#

### Устройство

Утилита полностью написана на C# — современном языке программирования с тесной интеграцией с Windows.

Никаких сторонних библиотек, скриптов или дополнительных файлов — только чистый код. 

> При этом размер программы составляет менее 300 КБ.

#

### Фишки

Hoster умеет не только добавлять, отключать и удалять записи, но и полноценно экспортировать и импортировать файл hosts.

Поддерживаются тихие ключи `-delete`, `-export` и `-import`, позволяющие использовать программу без запуска интерфейса.

А чтобы не скроллить целую вечность в поисках нужной записи, во встроенном поиске можно найти её по IP-адресу, домену или комментарию.

> [!Tip]
> Для быстрого импорта можно просто перетащить файл бэкапа на EXE-файл программы.
